# Blog Website Using CSS Grid

A responsive blog website layout built using **HTML5 and CSS3**. This project demonstrates the use of CSS Grid, Flexbox, media queries, and modern CSS styling to create a clean and responsive blog card layout.

## 🚀 Project Overview

The Blog Website displays multiple blog cards in a responsive grid layout. Each card contains a blog image, title, description, author information, and category.

The layout automatically adjusts according to the screen size, providing a better viewing experience on mobile, tablet, and desktop devices.

## ✨ Features

- Responsive blog card layout using CSS Grid.
- Dynamic column adjustment using CSS media queries.
- Flexbox for aligning card content and footer elements.
- Rounded card corners with borders.
- Author profile images with circular styling.
- Category labels for blog posts.
- Modern gradient background using OKLCH color values.
- Clean and simple user interface.

## 📱 Responsive Design

The website uses CSS media queries to adjust the number of columns according to screen width.

| Screen Width | Grid Columns | Grid Rows |
|---|---:|---:|
| Below 640px | 1 | 8 |
| 640px – 934px | 2 | 4 |
| 935px – 1249px | 3 | 3 |
| 1250px and above | 4 | 2 |
